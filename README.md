# Mi Transformación — GitHub Pages

Versión estática: no requiere npm, React, Vite ni build.

## Publicar
1. Subir todos los archivos de esta carpeta a la raíz del repositorio.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main / root.
5. Guardar.

La URL será `https://TU-USUARIO.github.io/TU-REPOSITORIO/`.

Los datos personales se guardan en `localStorage` del navegador.

## Funciones
- Rutina personalizada de 4 días.
- GIF/demos integradas en la propia web.
- Registro de series y cargas.
- Historial de progreso por ejercicio.
- Plan nutricional de 14 días.
- Historial de comidas.
- Persistencia de sección y posición.
- Jornada nutricional desde las 06:00.
- Respaldo JSON.
- PWA básica.
