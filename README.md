# Mi Transformación Pro V5 — Cardio integrado

Mantiene toda la V4 Nutrición Pro y reincorpora los bloques de cinta y recuperación.

Cada rutina ahora incluye:
1. Caminata en cinta de calentamiento.
2. Rutina de fuerza.
3. Cardio final / HIIT correspondiente al día.
4. Estiramiento final de 5–7 minutos.

Además se puede registrar:
- tiempo real;
- distancia;
- calorías;
- bloque completado.

Los perfiles de cinta son los que ya habíamos definido para cada día.
Compatible con GitHub Pages: index.html único + .nojekyll.
